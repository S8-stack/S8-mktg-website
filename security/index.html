Security

Zero dependencies is a security posture, not a slogan. Still, software has bugs. Tell us.

Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Email contact@alphaventor.com with steps to reproduce, affected modules, and impact. We will acknowledge the report and work a fix before any disclosure.

What we already take off the table

  • No nested third-party module graph under the core stack.
  • HTTP/2 and TLS in the default server path, with a restrictive inner policy.
  • Flows are short-lived. Do not cache them; the runtime will not either.
