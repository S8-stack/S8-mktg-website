S8-core-arch-silicon

The heartbeat of the system

The S8 core system embeds a powerful application-wide thread pool of workers with task profile identification. Everything is packed under the SiliconEngine object and is available everywhere.

Support different types of tasks

  • Reasonably non-blocking tasks (AsyncSiTask): expected to end in a finite amount of time. Each comes with a profile that indicates the expected run duration.
  • Blocking tasks (WatchSiTask): can block indefinitely and are therefore parked in a specific area of the engine.
  • Timed tasks (CLockSiTask): periodically called back.

S8-core-bohr-atom

The reference serialization protocol for all things S8

Bohr is a kind of ultimate protocol that tremendously upgrades the currently ubiquitous JSON format. Its super powers come from the fact that it natively enables:

  • Efficient serialization: serialize pretty much everything and natively support objects that come with specific native serialization methods (blending), like matrices, vectors, pictures.
  • Native compression: BOHR is a binary protocol, enabling bit-optimized flow for file size and stream bandwidth. Virtually all repetitions are removed in a single pass, merging the serialization pass and the compression pass into an ultimately fast processing.
  • Self-standing: BOHR is an auto-documented protocol, meaning that all structures of objects are completely recorded into the file/stream, in an incremental way tolerant to data model evolutions.
  • Sequence of deltas: think of BOHR as a blockchain-type protocol. Data can always be reconstructed through time, making the do/undo pattern easy to implement.

Usages

  • Persistency: used for the Beryllium, Neodymium, and Lithium object persistency handlers.
  • Streaming: BOHR is massively used to push objects from the back to the front, leveraging the native caching it offers.
